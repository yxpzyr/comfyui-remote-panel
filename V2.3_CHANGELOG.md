# V2.3 Changelog

## Task-level gallery and final-output workflow

- Gallery now paginates by **generation task**, not by raw image count.
- Added previous/next page buttons, direct page-number jump by Enter, and selectable page sizes: **5 / 10 / 20 tasks**.
- Removed the 5-second full-gallery polling loop. Gallery refreshes on entry/resume and by explicit Refresh action.
- Only the final-image thumbnails for the **current page** are downloaded, reducing mobile data usage and UI stalls.
- Each task shows only its final image in the main gallery. Long-press multi-select downloads final images only.
- Tapping a gallery task opens the final-image preview. Multi-image tasks add **查看全部图** to open the task's full output browser.
- Added `TaskOutputActivity` for viewing all process/final outputs of one task, with long-press multi-select download.

## Final-image detection

- V2.3 no longer assumes the first returned image is final.
- Generation monitoring waits for ComfyUI to mark the entire prompt complete before finishing the local task.
- While a task runs, output images are recorded in first-seen order and persisted.
- `generatedAt` prefers the output node's WebSocket execution timestamp; `outputOrder` breaks ties.
- Final output is selected by newest `generatedAt`, then highest `outputOrder`.
- Legacy V2.2 history without those fields falls back deterministically to the later returned image.
- `ImageRef` now stores `sourceNodeId`, `generatedAt`, and `outputOrder` with backward-compatible JSON parsing.

## Home output behavior

- The home screen downloads and displays **only the final image** of the latest completed task.
- Multi-image tasks show a `📁 N` button over the final image’s lower-right corner.
- “保存这张” saves only the final image.
- “全部保存当前输出” still downloads every image belonging to that task, on demand.

## Compatibility

- Existing V2.2 job records remain readable.
- Old jobs with no V2.3 generation-order metadata continue to appear using a conservative fallback order.
- V2.2 mask editing, persistent inputs, batch generation, themes, backgrounds, splash image and launcher icon switching are preserved.
