# V2.4 Changelog

## Batch workflow import

- The workflow picker now supports selecting one or many JSON files in one operation.
- A whole import batch is assigned to one logical workflow folder before parsing begins.
- Import is sequential and bounded to the existing 32 MiB per-file limit, avoiding a large simultaneous memory spike.
- One malformed/incompatible workflow no longer aborts the rest of the batch. The completion dialog reports successful and failed files separately.
- Batch import keeps the previously active workflow. If the library was empty, the first successful import becomes active.
- Concurrent workflow-import batches are blocked to avoid duplicate-name races and conflicting store writes.

## Workflow folders

- Added persistent one-level logical folders with stable UUIDs.
- Existing V2.3 workflows automatically appear under the system `未分类` category; their workflow IDs and saved inputs/masks remain unchanged.
- Added category filters: `全部工作流`, `★ 常用`, `未分类`, and user-created folders.
- Added create, rename and delete-folder management.
- Deleting a folder never deletes workflows; its workflows are moved to `未分类`.
- `管理当前` can move the active workflow between folders without recreating it or changing its workflow ID.
- Workflow names are unique only inside the same folder. Different folders may contain the same display name.
- Moving/deleting into a destination that already contains the same name automatically adds a `(2)`, `(3)` suffix instead of overwriting anything.

## Mask editor precision

- Single-finger drawing/erasing remains unchanged.
- Two fingers now zoom the canvas from fit-to-screen up to approximately 10x and can pan the enlarged canvas.
- Pinch/pan never edits the mask and does not consume undo/redo history.
- When a second finger is added during the first touch, the in-progress stroke is rolled back to prevent an accidental dot at the start of a pinch gesture.
- Brush size stays visually stable on screen, so zooming in makes the brush footprint smaller in original-image pixels for fine mask work.
- Zoom/pan changes only the editor view; saved mask coordinates and the original-image RGB/Alpha export logic are unchanged.

## Signing / compatibility

- Version: `versionCode 14`, `versionName 2.4.0`.
- Keeps the V2.3 permanent PKCS12 release-signing setup and signed GitHub Actions artifact (`ComfyUI-Remote-Panel-signed`).
- No workflow-storage reset is required when upgrading from the permanently signed V2.3 build.
