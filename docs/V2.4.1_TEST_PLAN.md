# V2.4.1 测试计划

1. 从固定签名 V2.4 覆盖安装 V2.4.1，确认数据保留。
2. 进入“工作流库”，确认首页先显示文件夹，而不是分类筛选弹窗。
3. 点“＋ 新建文件夹”，创建“动漫转真人”，确认进入该文件夹。
4. 在文件夹内多选导入 3 个 JSON，确认都进入当前文件夹。
5. 返回根目录，选择“📂 导入整个文件夹”，选一个包含 JSON 和非 JSON 的目录：
   - 自动创建与手机目录同名的 App 文件夹；
   - JSON 被导入，非 JSON 被忽略；
   - 坏 JSON 只单项失败。
6. 再次导入同名手机目录，确认自动创建 `(2)` 文件夹，不覆盖旧分类。
7. 在工作流菜单中移动工作流到其他文件夹，确认工作流 UUID/输入图/蒙版/参数记忆不丢。
8. 删除自定义文件夹，确认工作流进入“未分类”，不会被删除。
9. 在工作流库点击任意工作流，确认返回主页并切换为该工作流。
10. 主页横向快捷条只显示当前工作流所在文件夹中的工作流。
11. 蒙版编辑器继续验证双指缩放/平移、单指绘制和保存结果。
