# V2.5 测试计划

## A. 工作流搜索

1. 工作流库根目录、普通文件夹、未分类页面均应看到右下角 `🔍`。
2. 输入工作流名称片段，应即时出现匹配结果。
3. 输入文件夹名称，应找到该文件夹里的工作流。
4. 点击结果应切换当前工作流并返回主页。
5. 搜索前后文件夹、名称、收藏状态不得发生变化。
6. 100+ 工作流时搜索框输入/删除字符不应明显卡死。

## B. 参数识别

1. 展开高级设置后，参数区应按节点折叠显示。
2. 对含 KSampler / BasicScheduler / LoraLoader 等工作流，至少应看到 steps、cfg、denoise、strength 等 literal 参数。
3. 点击“重新检测参数节点”，连接正常时应显示检测数量并读取 `/object_info`。
4. COMBO 应使用下拉框，不允许提交不在当前电脑端定义中的选项。
5. INT/FLOAT 应显示 min/max/step（节点定义提供时）。
6. 已由上游连接的输入不应被当成 literal 参数编辑。
7. image_upload 不应出现在参数区。

## C. 临时与永久保存

1. 修改参数后“保存参数改动”应立即出现。
2. 不保存直接生成，应使用临时值。
3. 不保存后尝试切换工作流，应出现保存/放弃/取消提示。
4. 选择取消，应留在原工作流且保留当前临时值。
5. 选择放弃，应恢复最后保存值。
6. 点击保存后按钮应隐藏；切走再回来应保留保存值。
7. 输入非法数字或超出 min/max，生成/保存应被本地拦截并指出节点和参数。

## D. 回归

1. 批量导入 JSON。
2. 导入整个文件夹。
3. 新建/重命名/删除/移动工作流文件夹。
4. 蒙版单指绘制、双指缩放与平移。
5. 图库分页、最终图、查看全部图、多选下载。
6. GitHub Actions `assembleRelease` 产物保持 `ComfyUI-Remote-Panel-signed`。
7. V2.4.1 固定签名 APK 可直接覆盖安装 V2.5。
