# V2.4 focused test plan

## Upgrade / signing
- [ ] Install V2.4 directly over the permanently signed V2.3 without uninstalling.
- [ ] Existing V2.3 workflows still exist and appear under `未分类`.

## Batch workflow import
- [ ] Select 1 JSON file and import successfully.
- [ ] Select 5+ JSON files and import all into one chosen folder.
- [ ] Mix valid and invalid JSON files: valid files import; bad files are reported but do not cancel the batch.
- [ ] Import two same-named files into the same folder: suffixes are added instead of overwriting.
- [ ] Import same-named workflows into different folders: both may keep the same name.
- [ ] Existing active workflow remains active after a batch import.
- [ ] A second import cannot start while the first batch is still processing.

## Folder management
- [ ] Create multiple folders and filter the horizontal workflow strip by folder.
- [ ] `全部工作流`, `★ 常用`, `未分类`, and custom folder filters work.
- [ ] Rename a folder without losing workflows.
- [ ] Move a workflow to another folder; remembered input image, mask, parameters and output-node selections remain intact.
- [ ] Delete a folder containing workflows; workflows move to `未分类` and are not deleted.
- [ ] Move a workflow into a folder containing the same name; automatic suffix avoids overwrite.

## Mask pinch zoom
- [ ] One finger paints normally at 1x.
- [ ] Two fingers pinch from 1x to high zoom without painting accidental dots.
- [ ] Two fingers pan while zoomed in.
- [ ] After zooming, a small brush can accurately paint a tiny region.
- [ ] Eraser works while zoomed.
- [ ] Undo/redo affects mask edits but not pinch/pan operations.
- [ ] Saving while zoomed writes the correct full-image mask, not a cropped/translated view.
- [ ] Clear/invert while zoomed keeps the current zoom view and produces the correct mask.
