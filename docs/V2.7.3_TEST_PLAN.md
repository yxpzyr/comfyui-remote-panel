# V2.7.3 实机验证计划

1. 先备份 ComfyUI 的 `output`、`temp` 及安卓 `Pictures/ComfyRemote`，保留旧 App 数据；不要清空历史。
2. GitHub Actions 编译成功后使用既有固定签名直接覆盖安装 V2.7.2。
3. 使用原始 Qwen Image 2.1 四功能合集，选一个输出分支连续提交 2 次；在 `output` 文件夹检查 `QW21-YYYYMMDD_HHMMSS_SSS_<jobid>_00001_.png` 是否各不相同、实际文件是否存在。
4. 再用批量输入连续提交两项任务，检查新文件名前缀不同。
5. 同一最终图连续点击“保存这张”两次，检查手机 `Pictures/ComfyRemote` 中产生两份文件、均为原画质；已有 `%date:...%` 的旧任务应当也可以下载。
6. 打开图库刷新：同一个服务器文件路径的历史任务不应再铺满重复封面；新产生的不同物理输出文件应当各显示一次。
7. 进入全部过程图二级菜单，确认过程图、手动原图保存和分页仍正常；检查返回主页不白屏。
8. 使用普通单功能工作流（例如默认 `ComfyUI` 前缀）运行，确认文件命名和保存逻辑不被改写。
9. 保存前后对比新生成图片原始 PNG 字节与手机保存的文件字节；不得因缩略图优化降低保存质量。
