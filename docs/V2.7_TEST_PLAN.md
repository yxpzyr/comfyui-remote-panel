# V2.7 性能回归测试清单

## 行为
1. 进图库：本机已有任务先可用，后台合并远端历史；5/10/20 页大小、翻页、跳页、时间排序和名称排序与之前一致。
2. 翻页 1→2→3→1：旧页图片不会串到新页；第一遍和第二遍进入同图应明显减少图片网络流量。
3. 快速进入图库后立即退出：主界面不白屏，仍可触发生成，后台图库不继续下载已离开的页。
4. “查看全部图”中有 2/20/100+ 过程图：仅滑到对应位置才请求图片；长按全选、只选最终图和批量保存保持正常。
5. 预览打开和关闭、保存原图：预览可以快速显示压缩图，保存的是原件，且支持成功/失败提示。
6. 清理系统缓存后再打开：首批会重新获取预览，但不删除下载原图、生成历史或工作流配置。

## 性能建议（实测而非承诺）
- 分别在 Wi-Fi、移动代理网络中测首次打开图库和第二次打开：峰值下载速度、总下载字节、首屏出图耗时、内存峰值和是否掉帧。
- 用至少 1 张 4K PNG、100 个生成任务以及含 50 张过程图的复杂工作流压力测试。
- 如果仍然白屏：收集 Android `logcat` 中 `FATAL EXCEPTION`/`OutOfMemoryError`/ANR 及机型 Android 版本。
