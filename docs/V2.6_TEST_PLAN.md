# V2.6 测试计划

## 导入与检测

1. 将 Qwen Image 2.1 功能合集导入：应识别“图像编辑/高分图像编辑/图像扩展/生图”共四个独立子功能。
2. 普通单功能工作流：不显示“合集功能”按钮，原始运行流程保持一致。
3. 将 V2.5 已保存的合集在 V2.6 重新打开：无需重建工作流 UUID，分支入口出现，保留原输入和蒙版。

## 每个子功能

4. 逐项切换四个分支，验证输入图片数量、遮罩编辑器、参数节点列表和输出数量。
5. 编辑某一子功能的提示词、蒙版、采样步数，再切换分支又切回来，应保留这些状态。
6. 切换成功后检查生成任务的 API Prompt 仅有目标分支的 SaveImage；没有其他三条分支的输出。
7. 屏蔽某个自定义节点后尝试切换，提示缺少节点且保留原分支，不自动提交任务。
8. 逐项测试带和不带可选参考图的子功能，避免将 bypass 的 LoadImage 当作必填源。
9. 部分高级设置未保存时切换，依旧询问“保存/放弃/取消”。

## 回归

10. 图库分页、任务最终图/全图、文件夹上传/搜索、批量导入、蒙版双指缩放无回归。
11. GitHub Actions 执行 `assembleRelease` 成功并上传固定签名 app-release.apk。
12. 使用 V2.5 安装包覆盖升级到 V2.6，不删除 App 数据，旧普通工作流可正常执行。

## 尚需真机验证

自定义节点在用户的 ComfyUI 环境 `/object_info` 中的定义、各分支实际出图及性能只能通过用户连接的电脑端实际测试。
