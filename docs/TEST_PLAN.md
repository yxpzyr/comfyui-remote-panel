# V2.2 验收清单

## 1. 连接
- Termius/Tailscale 隧道未开启时，连接失败并给出中文错误。
- 隧道开启后输入 `8188` 可以连接。
- 重启 App 后记住上次地址。

## 2. 多工作流
- 导入一个普通 UI JSON，能通过 `/object_info` 转为可执行 prompt 并保存。
- 导入 API JSON，可直接保存。
- 退出并重开 App，工作流仍在，不需要重新导入。
- 连续导入多个工作流，可在顶部工作流条快速切换。
- 重命名、收藏置顶、删除都生效。
- 大型工作流保存在 App 私有文件目录，不依赖 SharedPreferences 存大 JSON。

## 3. 输入和参数
- 工作流有 1～N 个文件型输入图节点时都能显示。
- 每个输入可选择手机图片并预览。
- 开启“替换此输入”但未选图时，提交前明确提示。
- 关闭“替换此输入”时保留工作流原输入。
- 每个工作流的提示词/开关单独记忆，切换后不会串值。

## 4. 连续队列
- 提交第 1 张图后，等待“已加入队列”即可马上选择第 2 张继续提交。
- 第 1 张仍在生成时，第 2/3/4 张可以继续进入 ComfyUI 等待队列。
- 工作流 A 排队后切到工作流 B，B 的任务也能进入同一 ComfyUI 队列。
- 队列页正确显示上传中/等待中/生成中/同步结果/完成/失败/取消。
- 等待中的任务可以单独取消。
- 正在运行的任务可以请求 `/interrupt`。

## 5. history 兼容
- prompt-specific history 一完成就有图片时，立即完成。
- completed 先出现、图片 metadata 晚几秒出现时，App 不立即误报失败，而是继续同步。
- prompt history 没图但完整 history 有图时，能通过完整 history 找回。
- 自定义输出节点确实不返回任何 filename 时，任务标记为“已完成但无可下载图片”，而不是把生成本身判成失败。

## 6. 图库
- 最多显示最近 100 张。
- 时间最新优先/最早优先可切换。
- 名称 A-Z/Z-A 可切换。
- 点击图片可以预览并单独保存。
- 长按图片进入多选，继续点击可加/减选择。
- 全选、取消选择正常。
- 批量下载显示进度并保存到 `Pictures/ComfyRemote`。

## 7. 稳定性
- 快速连续排队多个任务时主界面不阻塞到上一任务生成完成。
- 切换工作流不会修改已经提交任务的 prompt 快照。
- App 重开后，有 prompt_id 的未完成任务会继续监控。
- 生成任务记录最多保留 250 条，避免无限增长。


## V1.9 夜间与后台专项
- [ ] 外观可在跟随系统 / 浅色 / 深色间切换，Main/Queue/Gallery 无明显白底漏色。
- [ ] 选择图片后自动上传，上传成功前开始生成不可点，成功后立即可点。
- [ ] 点击开始生成后输入区立即清空，可在上一任务未完成时继续选图并连续提交。
- [ ] 熄屏/切后台/切图库或队列后再回主界面，最近完成输出会自动追到最新。
- [ ] 图库停留 5 秒内能看到新完成图片，最近 100 张按时间/名称排序正常。
- [ ] 队列显示输入/输出缩略图、总体进度、队列位置、总用时/生成用时。
- [ ] 点击完成任务弹出原图，长按缩略图或大图保存成功。


## V2.0 多输出专项
- 导入包含 2 个及以上 SaveImage / PreviewImage 输出节点的工作流，应列出全部输出节点。
- 关闭其中一个输出节点后提交，ComfyUI history/最近输出只应出现启用输出节点对应图片。
- 尝试关闭最后一个输出节点时，App 应自动恢复并提示至少保留一个输出。
- 切换到另一个工作流再切回，输出开关状态应保持。
- 点击“重新检测输出节点”，应根据当前 `/object_info` 更新输出列表。
- 队列任务卡片应显示本任务输出节点选择摘要。

## V2.0 图标专项
- 桌面 Launcher、最近任务/应用信息页应显示霓虹节点沙发图标，而非默认 Android 图标。
- Android 8+ 自适应圆形/方形蒙版下，主体沙发与图片节点不应被裁掉。


## V2.1 输入常驻 / 批量 / 精简主页专项
- [ ] 工作流 A 选择输入图后切到 B，再切回 A，A 的图片仍恢复。
- [ ] 完成一次单张提交后，当前输入图不被清空，可以再次点击生成。
- [ ] 杀掉并重开 App 后，当前工作流恢复已保存 URI，并重新上传到 ComfyUI。
- [ ] 点击“清空本工作流已记住的输入图”后，仅当前工作流输入被清除。
- [ ] 批量选择 3～10 张后出现二次确认；确认后按系统返回顺序创建任务。
- [ ] 多输入工作流批量替换一个输入时，其余输入保持当前值。
- [ ] 首页启动时连接/参数/输出节点默认隐藏；展开后原功能全部可操作。
- [ ] 工作流横向快捷条和“工作流列表”均可切换工作流。

## V2.1 个性化专项
- [ ] 选择主界面背景后重建 MainActivity 仍能显示；清除后恢复主题背景。
- [ ] 选择启动页图片后，下次从 Launcher 启动显示自定义图。
- [ ] 自定义启动图 URI 失效时可自动回退默认启动页，不崩溃。
- [ ] 默认 / 极简节点 / 蓝色节点 3 个桌面图标可以切换，且应用不被杀死。

## V2.2 蒙版遮罩专项
- [ ] 标准 `LoadImage` 输入节点显示“编辑蒙版遮罩”。
- [ ] 普通不输出 MASK 的文件型图片节点不显示蒙版入口。
- [ ] `/object_info` 中输出包含 MASK 的自定义图片加载节点能够动态显示蒙版入口。
- [ ] `LoadImageMask` 的 channel=alpha 时显示蒙版入口；channel=red/green/blue 时不显示 Alpha 蒙版入口。
- [ ] 未选择图片时蒙版按钮不可用；选择图片后可进入蒙版编辑器。
- [ ] 涂抹时显示红色半透明区域，橡皮擦可以恢复区域。
- [ ] 画笔大小调节生效。
- [ ] 撤销 / 重做连续操作正常，超过 15 步不会异常。
- [ ] 反转蒙版与清空蒙版正常。
- [ ] 保存后主界面显示“已绘制蒙版”，并自动重新上传。
- [ ] ComfyUI 端 LoadImage 的 IMAGE 输出保持原图 RGB；MASK 输出与手机红色涂抹范围一致。
- [ ] 切换工作流再切回来，蒙版仍存在且可以继续编辑。
- [ ] 杀掉 App 重启后，保存的蒙版仍能恢复并重新上传。
- [ ] 更换输入图片时旧蒙版自动清除，不会错位沿用。
- [ ] 点击“清除蒙版”后重新上传无 Alpha 遮罩的原图。
- [ ] 点击“清空本工作流已记住的输入图”同时删除该工作流蒙版文件。
- [ ] 批量选择目标输入时不会把当前单张蒙版套到所有批量图片上。
- [ ] 大尺寸图片保存蒙版时保持原始分辨率，不应只上传编辑器预览分辨率。
- [ ] 带 EXIF 旋转的手机照片进入编辑器后方向正确，保存后蒙版位置不偏移。
