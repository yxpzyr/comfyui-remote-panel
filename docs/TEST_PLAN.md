# V1 验收清单

## 1. 连接
- Termius 本地转发未开启时，连接失败并显示中文错误。
- Termius 本地转发开启后，输入 `8188` 可以连接。
- 输入 `127.0.0.1:8188` 与完整 URL 都可以连接。
- 重启 App 后记住上次地址。

## 2. 工作流
- API 格式 JSON：正常读取并记住。
- 普通 UI 工作流：明确提示“请导出 API 格式”。
- 单个 LoadImage：自动选择。
- 多个 LoadImage：弹出中文节点选择框。
- 无 LoadImage：明确提示 V1 不支持。

## 3. 输入图
- 可从安卓文件选择器选择 PNG/JPEG/WebP。
- 左侧预览图正确显示。
- 上传 ComfyUI input 后，工作流对应节点的 image 字段被替换为上传后的文件名。

## 4. 生成
- 点“开始生成”后：上传 → 提交 → 轮询历史 → 获取输出。
- 右侧显示第一张输出图。
- ComfyUI 报错时，App 显示中文错误，不崩溃。
- “停止”可调用 `/interrupt`。

## 5. 保存
- 首页“保存输出”保存到 `Pictures/ComfyRemote`。
- 文件名尽量保留 ComfyUI 输出名。

## 6. 图库
- 打开“图库”可读取 ComfyUI 历史接口。
- 最多显示最近约 60 张，避免手机内存压力。
- 点击图片可放大预览并保存。

## 7. 网络安全
- App 只连接用户填写的地址。
- 推荐地址始终是 Termius 本地 SSH 转发 `127.0.0.1:<port>`。
- 不要求 ComfyUI 监听公网，不内置 SSH 密码，不保存 Termius 凭据。
