# V1.9 验收清单

## 1. 连接
- Termius/Tailscale 隧道未开启时，连接失败并给出中文错误。
- 隧道开启后输入 `8188` 可以连接。
- 重启 App 后记住上次地址。

## 2. 多工作流
- 导入一个普通 UI JSON，能通过 `/object_info` 转为可执行 prompt 并保存。
- 导入 API JSON，可直接保存。
- 退出并重开 App，工作流仍在，不需要重新导入。
- 连续导入多个工作流，可在顶部工作流条快速切换。
- 重命名、收藏置顶、删除都生效。
- 大型工作流保存在 App 私有文件目录，不依赖 SharedPreferences 存大 JSON。

## 3. 输入和参数
- 工作流有 1～N 个文件型输入图节点时都能显示。
- 每个输入可选择手机图片并预览。
- 开启“替换此输入”但未选图时，提交前明确提示。
- 关闭“替换此输入”时保留工作流原输入。
- 每个工作流的提示词/开关单独记忆，切换后不会串值。

## 4. 连续队列
- 提交第 1 张图后，等待“已加入队列”即可马上选择第 2 张继续提交。
- 第 1 张仍在生成时，第 2/3/4 张可以继续进入 ComfyUI 等待队列。
- 工作流 A 排队后切到工作流 B，B 的任务也能进入同一 ComfyUI 队列。
- 队列页正确显示上传中/等待中/生成中/同步结果/完成/失败/取消。
- 等待中的任务可以单独取消。
- 正在运行的任务可以请求 `/interrupt`。

## 5. history 兼容
- prompt-specific history 一完成就有图片时，立即完成。
- completed 先出现、图片 metadata 晚几秒出现时，App 不立即误报失败，而是继续同步。
- prompt history 没图但完整 history 有图时，能通过完整 history 找回。
- 自定义输出节点确实不返回任何 filename 时，任务标记为“已完成但无可下载图片”，而不是把生成本身判成失败。

## 6. 图库
- 最多显示最近 100 张。
- 时间最新优先/最早优先可切换。
- 名称 A-Z/Z-A 可切换。
- 点击图片可以预览并单独保存。
- 长按图片进入多选，继续点击可加/减选择。
- 全选、取消选择正常。
- 批量下载显示进度并保存到 `Pictures/ComfyRemote`。

## 7. 稳定性
- 快速连续排队多个任务时主界面不阻塞到上一任务生成完成。
- 切换工作流不会修改已经提交任务的 prompt 快照。
- App 重开后，有 prompt_id 的未完成任务会继续监控。
- 生成任务记录最多保留 250 条，避免无限增长。
