# V2.6.2 — Optional Reference Images & Accessible Parameter Titles

- Fixed clipped advanced parameter node captions: headers now wrap and grow to fit their content instead of using a fixed 44dp row.
- Fixed collection input detection: bypassed LoadImage source nodes upstream of the selected function are visible as optional reference images.
- Added an explicit per-branch switch for such inputs. Off keeps imported bypass semantics. On recompiles the selected branch with the required image/preprocessing chain enabled while leaving unrelated bypassed LoRA groups untouched.
- Image files, replace toggles, masks, and enabled auxiliary node selection are retained separately per subfunction. Upgrading V2.6.1 does not require deleting existing profiles.
- The compiler refuses invalid optional input IDs or dangling references, and errors leave the previous prompt active.
- Preserved PKCS12 permanent signing setup and other V2.5/V2.6 features.
