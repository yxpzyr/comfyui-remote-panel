# ComfyUI 远程面板（Android）V2.3

一个面向“手机 + Termius/Tailscale/SSH 转发 + 远程 ComfyUI”的中文 Android 控制端。

## V2.3 重点升级

V2.3 把“图库/输出”的基本单位从单张图片改成 **一次生成任务**，同时保留 V2.2 的手机蒙版遮罩能力。详见 `V2.3_CHANGELOG.md`。

- **任务级分页图库**：顶部提供上一页 / 下一页、页码输入回车跳转，并可选择每页 5 / 10 / 20 个任务。
- **真正减少流量**：图库不再每 5 秒全量刷新，也不会预下载 100 张缩略图；只下载当前页每个任务的最终图封面。
- **最终图优先**：任务完成后主页只显示最后生成的图片；复杂工作流产生的过程图不会再把主页撑得很长。
- **多图文件夹**：多图任务在主页最终图旁显示 `📁 N`，点击进入该任务全部图片的二级页面。
- **图库二级查看**：图库每个任务只显示最终图；点开预览后，多图任务会出现“查看全部图”。
- **多选规则更清晰**：图库直接长按只多选各任务最终图；只有进入任务全部图片页面后才可以多选过程图。
- **最终图顺序记录**：V2.3 等待整个 ComfyUI prompt 完成，并在运行中记录图片首次出现时间/顺序；最终图按最新 `generatedAt`、再按 `outputOrder` 判断。旧记录没有该数据时回退到返回顺序最后一张。
- **保存行为保持明确**：主页“保存这张”只保存最终图；“全部保存当前输出”仍按需下载该任务全部输出。
- **保留 V2.2**：MASK 自动识别、蒙版画板、输入图常驻、批量顺序生成、工作流列表、折叠高级设置、自定义背景/启动页/图标切换均继续保留。

### V2.2 蒙版能力继续保留

- 支持 MASK 的图片输入节点自动出现“编辑蒙版遮罩”。
- 支持涂抹、橡皮擦、画笔大小、撤销/重做、反转和清空。
- 蒙版写入 PNG Alpha，与 ComfyUI `LoadImage → IMAGE + MASK` 机制兼容。
- 蒙版按工作流/输入节点持久化，换图自动清除旧蒙版。

### 既有主要能力

- 多工作流常驻、快速切换、重命名、收藏置顶和删除。
- 普通 ComfyUI UI JSON + API JSON 导入。
- 连续排队 / 跨工作流排队 / 独立队列页 / 取消与中断。
- 每个工作流分别记住输入图、替换开关、提示词和控制参数。
- 批量多选图片按确认返回顺序单线程上传并创建任务。
- 主界面背景、启动页和 3 套内置 Launcher 图标。

## 使用前提

1. 电脑上的 ComfyUI 已启动。
2. 手机可以通过 Termius/Tailscale/SSH 隧道访问 ComfyUI，例如 `127.0.0.1:8188`。
3. 推荐不要把 ComfyUI 端口直接暴露到公网。

## 最简使用流程

1. 打开 App，输入 `8188` 或完整 ComfyUI 地址并测试连接。
2. 点“＋ 导入工作流”，选择一个 ComfyUI JSON。
3. 以后再次打开 App 时，这个工作流仍然存在，不需要重复导入。
4. 选择单张输入图后可直接生成；输入图会保留，不再自动清空。
5. 如果该输入节点支持 MASK，会出现“编辑蒙版遮罩”；进入画板涂抹并保存后，App 会自动重新上传原图 + 蒙版。
6. 要批量处理时点“批量选择”，多选后确认即可按顺序逐张入队。
7. 可切换到另一个已保存工作流继续提交任务。
8. 点“队列”查看所有任务状态。
9. 点“图库”按任务分页浏览；长按任务封面只多选最终图，点“查看全部图”进入单任务过程图页面。

## 地址规则

- `8188` → `http://127.0.0.1:8188`
- `127.0.0.1:8188` → 自动补 `http://`
- 完整 `http://...` / `https://...` → 原样使用

## 主要 ComfyUI 接口

- `GET /system_stats`
- `GET /object_info`
- `POST /upload/image`
- `POST /prompt`
- `GET /queue`
- `POST /queue`
- `GET /history/{prompt_id}`
- `GET /history`
- `GET /view`
- `POST /interrupt`

并对部分 `/api/...` 路径做回退尝试。

## 构建 APK（GitHub Actions）

工程自带 `.github/workflows/build-apk.yml`：

1. 将整个项目上传/推送到 GitHub 仓库。
2. 打开仓库 → **Actions** → **Build Android APK**。
3. 等待构建完成。
4. 在运行页面底部 **Artifacts** 下载 `ComfyUI-Remote-Panel-debug`。
5. 解压后安装 `app-debug.apk`。

## V2.3 数据保存

- 工作流正文保存在 App 私有目录 `workflows_v18`；V2.3 继续保存每个工作流的输入图片 URI、替换开关，并新增每个输入节点的蒙版文件路径。
- 蒙版 PNG 保存在 App 私有目录 `masks_v22`，更换输入图或清空工作流输入时会同步清理对应蒙版。
- 当前工作流、服务器地址、任务队列状态、图库每页 5/10/20 设置等轻量信息保存在 SharedPreferences。
- V2.3 任务输出记录新增 `sourceNodeId / generatedAt / outputOrder`，用于判定最后生成的最终图；旧记录保持兼容。
- 手机相册下载目录为 `Pictures/ComfyRemote`。

## 当前限制

- App 不负责建立 SSH/Tailscale 隧道。
- 如果 ComfyUI 启用了额外登录插件/Token，当前版本仍未提供认证字段。
- App 允许连续提交多个任务，但是否并行执行由 ComfyUI 和电脑端硬件决定；默认情况下应理解为“连续入队”，不是让多个任务同时抢同一块 GPU。
