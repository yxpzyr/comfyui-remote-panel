# ComfyUI 远程面板（Android）V2.2

一个面向“手机 + Termius/Tailscale/SSH 转发 + 远程 ComfyUI”的中文 Android 控制端。

## V2.2 重点升级

V2.2 在 V2.1 基础上新增 **手机端蒙版遮罩编辑器**。当输入图片节点支持 MASK 时，App 会自动显示“编辑蒙版遮罩”，并把绘制结果写入 PNG Alpha 后提交给 ComfyUI；普通输入节点不会显示。详见 `V2.2_CHANGELOG.md`。

- **MASK 节点自动识别**：核心 LoadImage/LoadImageMask(alpha) 可离线识别；连接 ComfyUI 后还会通过 `/object_info` 识别支持 MASK 的自定义图片加载节点。
- **手机端蒙版画板**：支持涂抹、橡皮擦、画笔大小、撤销/重做、反转和清空；红色区域就是最终 MASK 范围。
- **原图 RGB 不变**：蒙版写入 Alpha 通道后上传 PNG，与 ComfyUI `LoadImage → IMAGE + MASK` 原生机制兼容。
- **蒙版按工作流持久化**：每个工作流/输入节点分别保存；换图自动清除旧蒙版，避免错位。
- **保留 V2.1 全部能力**：输入常驻、批量顺序生成、工作流列表、精简首页、自定义背景/启动页和图标切换均继续保留。

- **输入图不再生成后清空**：每个工作流分别记住上次输入图与替换开关；重启 App 后可恢复并重新上传。
- **批量顺序生成**：每个输入节点都可批量选择；多张图片经确认后单线程顺序上传并创建任务，避免并发打乱。
- **工作流两种切换方式**：保留横向快捷按钮，同时增加完整工作流列表。
- **精简首页**：连接、提示词/开关、输出节点默认折叠，高频的输入、输出和生成操作保持直接可见。
- **个性化**：任意图片可作为主界面背景和启动页；桌面图标可在 3 个 APK 内置样式之间即时切换。

> Android 不允许已安装 App 把任意相册图片直接改成 Launcher 图标，因此“App 图标”采用 Activity Alias 切换预置资源；背景和启动页仍支持任意图片。


- **多工作流常驻**：工作流只需导入一次，之后保存在 App 私有目录中；支持同时保存多个工作流、快速切换、重命名、收藏置顶和删除。
- **普通 UI JSON + API JSON**：普通 ComfyUI UI 工作流会结合远程 `/object_info` 自动转换，API JSON 可直接使用。
- **连续排队生成**：一个任务成功提交到 ComfyUI 后，手机端立即恢复输入区；可马上换下一张图继续提交，不需要等上一张生成完。
- **跨工作流排队**：工作流 A 入队后可立刻切到工作流 B 再入队；真正的 GPU 执行顺序仍由 ComfyUI 队列决定。
- **独立生成队列页面**：显示上传中、等待中、生成中、同步结果、已完成、失败和已取消；等待任务可单独取消，运行中的任务可请求中断。
- **history 输出兼容增强**：任务完成后如果 prompt-specific history 暂时没有图片，会继续轮询并回退检查完整 history，避免过早误报失败。
- **100 张增强图库**：最多读取最近 100 张输出；支持时间升/降序、名称 A-Z/Z-A。
- **图库长按多选**：长按进入多选，可全选、取消选择、批量下载，并显示下载进度。
- **工作流参数分别记忆**：每个工作流单独保存提示词/开关等可编辑参数，不互相覆盖。
- **最近输出预览**：最近完成的可下载输出仍会回显在主界面，可单张或批量保存。

## 使用前提

1. 电脑上的 ComfyUI 已启动。
2. 手机可以通过 Termius/Tailscale/SSH 隧道访问 ComfyUI，例如 `127.0.0.1:8188`。
3. 推荐不要把 ComfyUI 端口直接暴露到公网。

## 最简使用流程

1. 打开 App，输入 `8188` 或完整 ComfyUI 地址并测试连接。
2. 点“＋ 导入工作流”，选择一个 ComfyUI JSON。
3. 以后再次打开 App 时，这个工作流仍然存在，不需要重复导入。
4. 选择单张输入图后可直接生成；输入图会保留，不再自动清空。
5. 如果该输入节点支持 MASK，会出现“编辑蒙版遮罩”；进入画板涂抹并保存后，App 会自动重新上传原图 + 蒙版。
6. 要批量处理时点“批量选择”，多选后确认即可按顺序逐张入队。
7. 可切换到另一个已保存工作流继续提交任务。
8. 点“队列”查看所有任务状态。
9. 点“图库”查看最近 100 张图片，排序或长按多选批量下载。

## 地址规则

- `8188` → `http://127.0.0.1:8188`
- `127.0.0.1:8188` → 自动补 `http://`
- 完整 `http://...` / `https://...` → 原样使用

## 主要 ComfyUI 接口

- `GET /system_stats`
- `GET /object_info`
- `POST /upload/image`
- `POST /prompt`
- `GET /queue`
- `POST /queue`
- `GET /history/{prompt_id}`
- `GET /history`
- `GET /view`
- `POST /interrupt`

并对部分 `/api/...` 路径做回退尝试。

## 构建 APK（GitHub Actions）

工程自带 `.github/workflows/build-apk.yml`：

1. 将整个项目上传/推送到 GitHub 仓库。
2. 打开仓库 → **Actions** → **Build Android APK**。
3. 等待构建完成。
4. 在运行页面底部 **Artifacts** 下载 `ComfyUI-Remote-Panel-debug`。
5. 解压后安装 `app-debug.apk`。

## V2.2 数据保存

- 工作流正文保存在 App 私有目录 `workflows_v18`；V2.2 继续保存每个工作流的输入图片 URI、替换开关，并新增每个输入节点的蒙版文件路径。
- 蒙版 PNG 保存在 App 私有目录 `masks_v22`，更换输入图或清空工作流输入时会同步清理对应蒙版。
- 当前工作流、服务器地址、任务队列状态等轻量信息保存在 SharedPreferences。
- 手机相册下载目录为 `Pictures/ComfyRemote`。

## 当前限制

- App 不负责建立 SSH/Tailscale 隧道。
- 如果 ComfyUI 启用了额外登录插件/Token，当前版本仍未提供认证字段。
- App 允许连续提交多个任务，但是否并行执行由 ComfyUI 和电脑端硬件决定；默认情况下应理解为“连续入队”，不是让多个任务同时抢同一块 GPU。
